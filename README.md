# July 9 Countdown · Midnights Era

A fan-made Taylor Swift–themed countdown to **July 9, 2026**, with carousels, dream-pop soundtrack, and sparkle.

## Live site (GitHub Pages)

After publishing, enable **Settings → Pages → Deploy from branch → `main` / root**.

Your site will be at:

`https://fongathan.github.io/countdown-july-9/`

## Local preview

Open `index.html` in a browser (keep the `carousel/` folder and `mixkit-*.mp3` files alongside it).

## Publish / update

From this folder, after [GitHub CLI login](https://cli.github.com/):

```bash
gh auth login
./publish-to-github.sh
```

Or create the repo on GitHub, then:

```bash
git remote add origin https://github.com/fongathan/countdown-july-9.git
git push -u origin main
```
